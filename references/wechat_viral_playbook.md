## 1. 标题公式：6 大黄金模板（3 秒点击法则）

微信公众号标题必须在 **3 秒内** 激发点击欲。**15-25 字**为宜。

| # | 公式 | 模板 | 例子 |
|---|------|------|------|
| 1 | **数字+悬念** | `N 个 X，Y` / `N 个原因` | `3 个 AI 工具，让我工作效率翻 10 倍` |
| 2 | **人群标签+利益** | `[人群] 必看 / 必知 / 必收藏` | `程序员必看的 5 个 AI 编程助手` |
| 3 | **反常识+悬念** | `不是 X，而是 Y` / `XX 的真相是` | `不是 AI 太强，而是你不会用提示词` |
| 4 | **热点+解读** | `刚刚 X，Y` / `X 炸了，Y` | `刚刚 OpenAI 发布了新模型，AI 行业格局变了` |
| 5 | **对比+反差** | `从 X 到 Y，我只用了 Z` | `从月薪 8K 到副业 3W，我只做了这件事` |
| 6 | **设问+答案** | `X？答案是 Y` / `X 到底怎么做？` | `AI 写作到底能不能赚钱？3 个月实战告诉你` |

## 3. 正文结构：4 大框架

### 框架一：问题导向型（教程、干货）
- 痛点引入 → 解决方案概览 → 分步讲解 → 案例展示 → 总结互动

### 框架二：热点解读型（资讯、事件分析）
- 事件回顾 → 背景科普 → 深度分析 → 趋势预测 → 互动话题

### 框架三：观点输出型（深度思考、行业洞察）
- 观点抛出 → 论证展开 → 反驳异议 → 升华行动 → 开放式结尾

### 框架四：清单汇总型（工具推荐、资源整理）
- 开场引入 → 清单呈现 → 总结点评 → 福利彩蛋
