# 小红书爆款方法论速查手册

> 给 AI/Claude 用的爆款写作内化指南。生成 `draft.md` 时按这套逻辑套模板，能显著提升进入二级流量池的概率。

## 1. 算法机制：阶梯式流量池 + CES 公式

小红书的笔记发布后，会被投放到层层递进的流量池：

| 层级 | 曝光量级 | 通过条件（约） |
|------|---------|---------------|
| 初级流量池 | 200-500 | CES > 同品类基准线（约 10） |
| 二级流量池 | 5,000-10,000 | CES 持续上涨 + 完播率 > 30% |
| 三级流量池 | 50,000+ | 评论率 > 1.5% + 收藏率 > 3% |
| 爆款池 | 100k+ | 互动持续 24h，无负反馈 |

**CES 评分（互动权重）**：

```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

→ **评论 / 转发 / 关注的权重远高于点赞**。结尾**必须**留一个能引发评论的开放问题，draft 模板里已硬编码这一行。

**完播率 > 30%** 是生死线：开头 3 秒钩不住人就直接出局。所以正文第一行必须是悬念 / 痛点 / 反常识。

## 2. 标题公式：五大黄金模板

标题占 70% 的点击决策。**永远不要**用纯描述式（"今天分享一条 AI 推文"）。从下面挑一个套：

| # | 公式 | 模板 | 例子 |
|---|------|------|------|
| 1 | 数字+痛点+方案 | `N 个 X，让你 Y` | `3 个被低估的 AI 工具，让你效率翻倍` |
| 2 | 人群标签+解决 | `[人群] 必看！X 解决 Y` | `打工人必看！这条推文解决了我加班的根本原因` |
| 3 | 反常识+悬念 | `不是 X，而是 Y` / `99% 的人都做错了` | `不是 AI 抢工作，而是不会用 AI 的人在被淘汰` |
| 4 | 实测+结果 | `亲测 N 天，X 真的能 Y` | `亲测 7 天，这个 Agent 帮我省了 20 小时` |
| 5 | 对比+反差 | `从 X 到 Y，我只做了 Z` | `从月薪 8k 到接单 5w，我只学了这一个技能` |

**加分项**：
- 加 1-2 个**话题相关 emoji**（不要堆砌，3 个以上反而减分）
- 数字优先用阿拉伯字（"3 个" 比 "三个" 点击率高约 12%）
- 长度 **18-22 字**最佳，别超过 25 字
- 含**目标人群词**（打工人 / 学生党 / 宝妈 / i 人 / 程序员…）

## 3. 封面设计三秒法则

> 用户在信息流里给一张图的判断时间 < 3 秒。

封面是 draft.md 里 `## 图集顺序` 第 1 张图。AI 生成 draft 时无法直接做封面，但可以在 draft.md 里写出**封面建议**（推文卡片截图 / 主图 / 信息密度图）。

**三色法则**：封面颜色不超过 3 种，主色占 70%、辅色 25%、点缀色 5%。
**字体规则**：标题 + 副标题，字号差至少 2 倍；标题用粗黑或可商用海报字体。
**九宫格构图**：核心信息放中心或右上，**左下**放 logo / 标签。

**主题专属规律**：
- 知识 / 干货：信息密度高、列点、强对比色
- 体育 / 时事：原图 + 大字号金句覆盖
- 时尚 / 生活：明亮、留白、低饱和
- AI / 科技：深色背景 + 霓虹高亮 + emoji

## 4. 正文结构：四种框架二选一

### AIDA（推荐用于产品 / 工具种草）

```
A  (Attention) - 1-2 行抓眼球的反差 / 痛点
I  (Interest)  - 引出本人故事或场景共鸣
D  (Desire)    - 列点说明利益（3-5 条）
A  (Action)    - 引导评论 / 收藏 / 关注
```

### SCQA（推荐用于深度内容 / 观点）

```
S  (Situation)  - 背景：现在大家都在 ___
C  (Complication) - 转折：但其实 ___
Q  (Question)   - 那应该怎么办？
A  (Answer)     - 我的方法 / 观察 / 解读
```

### PASS（推荐用于解决方案 / 教程）

```
P  (Problem)    - 你是不是也遇到过 ___
A  (Agitate)    - 这个问题如果不解决 ___
S  (Solution)   - 我的解法是 ___
S  (Story)      - 实操 / 数据 / 案例佐证
```

### Hook（推荐用于资讯 / 转发型）

```
开篇钩子 (1 行) - 反常识 / 数字震撼 / 悬念
正文段        - 3-5 段，每段 < 60 字，段间空行
金句收束       - 1 行能被截图传播的话
互动呼唤       - 开放问题
```

### 黄金开头公式（任选其一）

- **数字震撼**："99% 的人都不知道..."
- **反差对比**："别人花 3 天，我只用了 30 分钟"
- **痛点直击**："是不是每次都 ___ ？"
- **悬念前置**："看到最后一张图我惊了..."
- **场景代入**："凌晨 2 点的办公室，我盯着屏幕..."

### 格式硬指标

- 段落 ≤ 3 行，段间**留空行**
- 每 3-4 段插一个 emoji 视觉分隔
- 关键词**前后加空格**（小红书不支持 markdown 加粗，用 emoji 包裹关键词代替：`✨ 关键词 ✨`）
- 总字数 **300-800 字**（短了显单薄，长了完播率掉）
- 结尾**必须**有 1 个开放问题（CES 评论权重 ×4，最高 ROI 操作）

## 5. 标签 / 关键词策略：金字塔布局

```
顶层（1 个）：核心词       例：#AI Agent
中层（2-3 个）：长尾精准词   例：#AI工具推荐 #效率工具 #打工人神器
底层（3-5 个）：广义流量词   例：#职场 #副业 #干货分享 #成长
```

**总计 6-9 个标签**最佳，10+ 反而被算法判定为标签党降权。

**避坑**：
- 不要用纯品牌词标签（除非官方笔记）
- 不要用敏感词 / 极限词（最、第一、唯一）
- 优先复用**原推 / 原文里的话题词**（在 xhs_converter 里 `re.findall(r'#([\w一-鿿]+)', text)` 抽出）

## 7. 互动设计：CES 加分项

回想公式：`点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8`。

**评论引导技巧**（按权重从高到低）：

1. **结尾开放问题**（必备）："你们怎么看？" / "评论区分享一下你的 ___"
2. **争议性观点**："这件事我和大多数人想法不一样：___，你觉得呢？"
3. **求助式**："家人们救救我，___ 这个问题怎么破？"
4. **投票二选一**："A 还是 B？评论区站队"
5. **故意留错** / 钩子："最后一条很多人不知道，下篇说"

**收藏引导**（适合干货）：
- "建议先收藏再看，下次找不到了"
- "工具清单整理在最后，别错过"

**关注引导**（最大权重 ×8）：
- "我会持续更新这个系列，关注不迷路"
- "下一篇 ___，关注我看后续"

## 8. 选题：反漏斗法则

> 不是从大流量词往下找 niche，而是从你自己最熟的细分点往外辐射。

```
你的真实经历/技能 (核心)
    ↓
特定人群的具体痛点 (中层)
    ↓
泛人群的共鸣场景 (外层)
```

**例**：你是程序员用了 Claude → "程序员用 Claude 提效 10 倍"（核心）→ "打工人用 AI 工具提效"（中层）→ "AI 时代不被淘汰的能力"（外层）。

发布时**标题用外层词**（流量大），**正文用核心经验**（差异化），**标签金字塔覆盖三层**。

```
权重：    30%        20%         15%        25%        10%

CES：     评论4 + 转发4 + 关注8 + 点赞1 + 收藏1
              ↑          ↑
            开放问题   持续更新承诺
```
