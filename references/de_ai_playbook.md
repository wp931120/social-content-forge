# 去 AI 味写作指南

> 让 AI 生成的内容更像人写的。适用于生成小红书 / 微信公众号文案后的"人味化"处理。

---

## 1. AI 文字的典型特征（检测点）

| 特征 | 表现 | 如何识别 |
|------|------|----------|
| **过渡词堆砌** | "然而"、"此外"、"更重要的是"、"综上所述" | 一段话出现 3+ 次过渡词 |
| **句式单一** | 几乎每句都是同等长度、复杂句 | 缺乏长短变化 |
| **观点空洞** | "很重要"、"非常有意义"、"值得关注" | 缺少具体例子 |
| **结构死板** | "首先、其次、最后"、"第一、第二、第三" | 清单式列举 |
| **语气冷漠** | 过于正式、像百科全书 | 缺乏情感词 |
| **完美主义** | 逻辑过于严密、无漏洞 | 缺少"啊差点忘了"类打岔 |
| **格式堆砌** | 大量 Markdown（####、1.、**加粗**） | 机器感排版 |

## 2. 去 AI 味核心技巧

### 技巧一：增加个人痕迹

| 方法 | 示例 |
|------|------|
| **加入个人故事** | "上周我用了这个方法..." |
| **添加主观感受** | "说实话我一开始也不信，但..." |
| **使用口语词** | "啊对了"、"说起来"、"你们肯定遇到过" |
| **承认不完美** | "这个我也还在摸索"、"可能不是最优解" |

### 技巧二：打破句式规律

| 方法 | 示例 |
|------|------|
| **长短交错** | "效果好。" + "但如果你时间不够，只做第一步就够了。" |
| **偶有断句** | "就一个字——爽。" |
| **插入废话** | "对了，说到这个..." |
| **设问自答** | "有人可能会问：真的这么神？反正我用了两周是这样。" |

### 技巧三：砍掉过渡词

**AI 常用过渡词黑名单**：
```
然而、此外、与此同时、更重要的是、综上所述、
首先、其次、最后、总的来说、由此可见
```

**替代方案**：
- 直接删掉，让句子自然承接
- 换成口语："然后"、"对了"、"说到这个"
- 用句号断开，硬切话题

### 技巧四：去格式化

| AI 习惯 | 怎么改 |
|---------|--------|
| "## 标题" | 改成自然分段，或用 emoji 替代 |
| "1. 2. 3." | 改成 "第一点"、"再说一点" |
| "**加粗**" | 直接用词，或用 ~下划线~ 代替 |
| 大量 bullet 点 | 改成自然段落描述 |
| "总结：" | 改成 "总之吧"、"这么一说吧" |

### 技巧五：加入具体细节

| AI 空洞表述 | 改成具体细节 |
|------------|-------------|
| "效果很好" | "用了三天阅读量从 200 涨到 2000" |
| "很多人都在用" | "我身边 5 个程序员朋友都在用" |
| "需要注意" | "我第一次就踩了这个坑..." |

## 3. 分平台处理

### 小红书

- **保留 emoji**：小红书本身就适合 emoji，这反而是"人味"
- **加入互动**：评论区见、你们用过吗、求赞
- **短句优先**：每段不超过 2 行
- **话题标签**：但别太多，3-5 个足够

### 微信公众号

- **去 Markdown**：公众号编辑器会自动处理格式
- **段落更长**：可以 3-4 行一段
- **观点鲜明**：可以有争议性观点
- **结尾互动**：必做三件套（总结 + 问题 + 行动号召）

---

## 4. 快速自检清单

生成文案后，用这个清单快速检查：

- [ ] 是否有至少 1 个个人故事/例子？
- [ ] 是否有口语词（啊、对了、话说）？
- [ ] 过渡词是否 ≤2 个/段？
- [ ] 句式是否有长短变化？
- [ ] 是否去掉了 Markdown 格式？
- [ ] 观点是否有具体数据/案例支撑？
- [ ] 结尾是否有互动引导？

---

## 5. 一句话速记

```
去 AI 味 = 加人话 + 砍过渡 + 破句式 + 去格式 + 添细节
```

---

## 6. 给 Agent 的指令模板

如果需要让 AI 重新"人味化"文案，可以直接用这个提示：

```
请把以下文案重新改写，去除 AI 味道：
- 加入至少一个个人故事或具体例子
- 砍掉所有"然而、此外、首先、其次"类过渡词
- 打破均匀句式，长短交错
- 删除 Markdown 格式符号
- 加入口语词（啊、对了、话说）
- 保持核心观点不变，只调整表达方式
```

或更简单：直接说"用你妈妈能看懂的大白话重写一遍"往往比复杂指令更有效。
